# CLAUDE.md

Personal portfolio of **Sercan Erhan** (CPO, Basefy Innovation Lab).
Live: https://sercanerhan.github.io/portfolio/ · Repo: https://github.com/sercanerhan/portfolio

A single-page "Product OS" style site (dark, Linear/Vercel feel) with an impact dashboard, deep-linkable case studies, seven playable product demos, a career changelog and a ⌘K palette. The site itself is a showcase that Sercan can build with AI — treat it like a product, not a template.

## Commands

```bash
npm run dev                          # Vite dev server (http://localhost:5173)
npm run build                        # build-stats → tsc → vite build (output: dist/)
BASE_PATH=/portfolio/ npm run build  # build exactly as GitHub Pages serves it
npm run preview                      # serve dist/ (combine with BASE_PATH to test the sub-path)
npm run images                       # assets-src/generated/*.png → public/images/*.webp + public/og-image.jpg
npm run stats                        # refresh src/data/buildStats.json (also runs on build)
node scripts/build-map.mjs           # regenerate src/data/worldmap.json (dotted world map)
scripts/generate-images.sh           # generate cover art with the Codex CLI (see "Images")
```

There is no test suite; `npm run build` (which type-checks) plus a browser check is the verification bar.

## Stack

React 19 · TypeScript 7 · Vite 8 · Tailwind CSS 4 (`@tailwindcss/vite`, tokens in CSS) · `motion` (import from `motion/react`) · `cmdk` · `lenis` · `lucide-react` v1 (no brand icons — use `components/BrandIcons.tsx`) · self-hosted fonts via `@fontsource-variable`.

## Content rules (non-negotiable)

- **Facts are fixed.** Company names, titles, dates and education must match the CV exactly. Current company is **"Basefy Innovation Lab"** (the CV's "Basefu Onnovation Lab" is a typo).
- **No invented metrics.** Only reuse numbers already on the CV: +142% engagement, +52% users, +40% revenue, +70% CSAT, 24 countries, 4 new countries / 2 regions, 65% QoQ growth, 16 dependent services, 100% exit in 16 months, 5 PMs hired, $11M annual savings ($8M from data consolidation), 101 departments, 30+ / 12 / 40+ engineers, 18 ministries / 3,000 municipalities. Career length is "18 years" (since 07.2008).
- **Illustrations must be labelled.** Demo UIs are recreations or simulations — keep the `DemoNote` / "Illustrative recreation" / "Simulation" labels on anything that could be mistaken for a real company screen or real data.
- **Privacy.** No phone number anywhere. Never commit `cv_sercanerhan_*.pdf` (it is git-ignored; keep it that way).
- **Tone.** A showcase of the whole career — never "open to opportunities" or job-hunting language.
- Copy edits go in `src/data/profile.ts`, not in components.

## Conventions

- **Styling:** Tailwind utilities with the theme tokens (`bg-bg`, `bg-surface`, `text-fg`, `text-muted`, `text-subtle`, `border-line`, `border-line-strong`, `text-accent`, `text-accent-2`). Reuse the `card`, `eyebrow`, `text-gradient` utilities. Dark only.
- **Motion:** entrance animations through `<Reveal>`; numbers through `<CountUp>`; hover glow through `<SpotlightCard>`. Everything sits under `<MotionConfig reducedMotion="user">` — keep new animation compatible (no motion-only meaning, SVG `animateMotion` gated on `useReducedMotion()`).
- **Sections:** a new top-level section needs an `id`, an entry in `lib/sections.ts` (nav + palette pick it up) and a `<SectionHeader eyebrow title intro>`.
- **Routing:** hash-only (`#/work/<slug>`) because GitHub Pages has no rewrites. Do not add a router that needs server fallbacks.
- **Assets:** always reference files in `public/` via `asset('images/x.webp')` — never a leading `/`, or the `/portfolio/` sub-path breaks.
- **Demos:** each demo is lazy-loaded in `Showcase.tsx`; self-contained, no network calls, no API keys; must work with mouse, touch and keyboard.
- **Scrollable inner panels** (modals, consoles) need `data-lenis-prevent` so Lenis doesn't hijack wheel events.
- Match the existing code style: function components, named exports, light comments only where intent isn't obvious.

## Images (Codex CLI, no API key)

Art is generated with the **Codex CLI on Sercan's ChatGPT subscription** — never use an OpenAI API key. `scripts/generate-images.sh` holds the shared style prompt. Gotcha: `codex exec` must get `< /dev/null` or it hangs on "Reading additional input from stdin" when run in the background. After generating, run `npm run images` and look at the result before committing. See the `generate-image` skill.

## Deploy

Push to `main` → `.github/workflows/deploy.yml` builds with `BASE_PATH` from `actions/configure-pages` and deploys to Pages (Pages source is already set to "GitHub Actions"). Check with `gh run list -R sercanerhan/portfolio`. Pushing publishes publicly — confirm with Sercan before pushing. See the `ship` skill.

## Claude Code setup

`.claude/settings.json` (shared) pre-allows the build/preview/stats commands, asks before `git push` and image generation, and blocks force-pushes and staging the CV. Project skills in `.claude/skills/`:

| Skill | Use it to |
| --- | --- |
| `ship` | build under `/portfolio/`, preview, commit, push (after asking), watch the Pages deploy |
| `generate-image` | create or redo artwork with the Codex CLI and optimize it to WebP |
| `add-case-study` | add a deep-linkable case study with sourced metrics and a cover |
| `add-showcase-demo` | build a new playable product demo for the showcase tabs |
| `content-audit` | fact-check copy against the CV, metric allow-list, privacy and tone rules |

Machine-specific files (`.claude/launch.json`, `.claude/settings.local.json`, `CLAUDE.local.md`) are git-ignored.
